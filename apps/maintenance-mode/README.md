# BärGPT Maintenance Mode

This is the maintenance page for the _BärGPT_ project.

It's a minimal static React page shown to users when BärGPT is temporarily unavailable (during downtime or when the system is overloaded). It offers a reload button and a link to the help site. It needs no environment configuration.

## Development

This app is part of the BärGPT monorepo. For prerequisites and how to run everything locally, follow the development guide at [`../../README_DEV.md`](../../README_DEV.md).
