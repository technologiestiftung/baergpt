# BärGPT Frontend

This is the main user-facing web app for the _BärGPT_ project.

It's a React single-page app that provides the chat interface, document upload with RAG search, markdown rendering, and document export (DOCX/PDF). It talks to the [backend](../backend) API and Supabase for auth and data.

## Development

This app is part of the BärGPT monorepo. For prerequisites, environment setup, and how to run everything locally, follow the development guide at [`../../README_DEV.md`](../../README_DEV.md).

The dev server runs on `http://localhost:5173`.
