# BärGPT Admin Panel

This is the administration panel for the _BärGPT_ project.

It's a React app used to manage the base knowledge (RAG documents), the domain and individual email allowlists, users, and the product/usage dashboard. It talks to the [backend](../backend) API and Supabase for auth and data.

## Development

This app is part of the BärGPT monorepo. For prerequisites, environment setup, and how to run everything locally, follow the development guide at [`../../README_DEV.md`](../../README_DEV.md).

The dev server runs on `http://localhost:5174`.
